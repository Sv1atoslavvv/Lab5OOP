# Lab5OOP — профспілка

Навчальний проєкт з ООП на C++17: абстрактні класи, поліморфізм, множинне успадкування, винятки та робота з файлами.

## Збірка

Потрібні CMake і компілятор із підтримкою C++17.

```sh
cmake -S . -B build
cmake --build build
```

Запуск із файлом даних:

```sh
build/profspilka_oop_lab5 voucher_data.txt
```

Якщо аргумент не вказано, програма використовує `voucher_data.txt` у поточній директорії.

## Структура

- `include/` — заголовки класів і сервісів.
- `src/` — реалізація програми.
- `voucher_data.txt` — початкові дані.
- `uml_class_diagram.png` і `uml_class_diagram.svg` — діаграми класів.
